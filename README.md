# 명조 · 공명전선

명조 캐릭터 24명으로 조합을 실험하는 비공식 로컬 팬 프로토타입. 혼자 9구역 원정 또는 같은 와이파이에서 2~8인 대전. 기존 애니메이션 크로스오버 게임과 별도 폴더로 유지합니다.

## 실행

이 폴더에서 `npm start`, 브라우저에서 http://localhost:4190/ 를 엽니다. Node.js 필요. `npm test`로 전투·경제·저장 검사를 실행합니다.

## 플레이

1. 금희 협동 / 카멜리아 연격 / 기염 기류 / 앙코 용융 / 상리요 전도 중 시작 팀을 고릅니다.
2. 상점에서 같은 캐릭터 3명을 모으면 자동 승급합니다. 캐릭터 선택 후 빈 전장·대기석 칸을 누르면 이동합니다.
3. 캐릭터를 선택하고 에코 가방의 장비를 눌러 장착합니다.
4. 전투는 자동 진행됩니다. 협주 100일 때 총공격 버튼을 직접 누릅니다.
5. 전투 후 에코와 다음 경로를 선택합니다. 3·6구역에서 공명 변주를 선택하고 9구역까지 도전합니다.

준비 단계가 브라우저에 자동 저장됩니다. 전투 중 새로고침은 전투 직전 준비 단계로 돌아갑니다. 보상 선택 중 저장은 지원하지 않습니다. 새 원정은 확인 후 저장을 초기화합니다.

## 2026-10-13 · 함께 대전(멀티) + 공명자 8명 추가

### 함께 대전 실행
1. 방장 컴퓨터에서 `npm start` (또는 `플레이.command`). 터미널에 `같은 와이파이 친구 접속 → http://192.168.x.x:4190/` 주소가 표시됩니다. macOS 방화벽 허용 창이 뜨면 허용하세요.
2. 방장: **함께 대전 → 방 만들기**. 4자리 방 코드가 나옵니다.
3. 친구: 같은 와이파이에서 위 주소 접속 → **함께 대전** → 코드 입력 → 참가. 인원이 부족하면 방장이 **봇 추가**(최대 8명).
4. 방장이 준비 시간(25/40/60초)을 고르고 **대전 시작**.

### 규칙 (TFT식 최후의 1인)
- 시작 팀 선택(25초) → 매 라운드 준비(제한 시간) → 무작위 상대와 자동 전투 → 진 쪽 생존력 감소. 생존력 100, 0이 되면 탈락.
- 패배 피해 = 2 + ⌊라운드/3⌋×2 + 상대 생존 유닛 ★ 합. 홀수 인원이면 한 명은 다른 플레이어 덱의 **잔상**과 싸웁니다(잔상 주인은 피해 없음).
- **공용 모집 풀**: 1코스트 22장 / 2코스트 18 / 3코스트 14 / 4코스트 10. 누군가 모집하면 풀에서 빠지고, 판매·탈락 시 돌아옵니다. 라운드가 오를수록 고코스트 등장 확률 상승.
- 수입 = 5 + 이자(10코인당 1, 최대 5) + 승리 1 + 연승·연패 보너스(3연 1, 5연 2).
- **출전 +1**(4G부터 2G씩 증가, 최대 8명). 2·5·8… 라운드에 공명 변주, 매 라운드 에코 선택.
- 협주 총공격은 멀티에서 100이 되면 자동 발동(양측 모두). 상단 플레이어 카드를 누르면 상대 덱을 정찰합니다.
- 모두 **준비 완료**를 누르면 시간 전에 전투 시작, 모두 결과를 확인하면 다음 라운드. 새로고침해도 같은 탭이면 방에 다시 접속합니다.
- 서버는 방장 컴퓨터에서만 돌고 인터넷 공개 서버가 아닙니다. 방은 30분간 활동이 없으면 정리됩니다.

### 구조
- `engine.js` — 전투·경제(브라우저·서버 공용). 양측 대칭 전투(`makeDuel`/`runDuel`), 공용 풀, 출전 확장 추가. 혼자 원정 규칙은 그대로.
- `multi.mjs` — 방 규칙(로비·라운드·매칭·탈락·봇 AI). HTTP와 분리되어 테스트에서 직접 구동.
- `server.mjs` — 정적 파일 + `/api/*`(SSE 스트림 + JSON). 추가 패키지 없음. `HOST=127.0.0.1 npm start`로 이 컴퓨터 전용 실행.
- 전투 재생 데이터는 변화분만 보내도록 압축(한 판 약 527KB → 23KB).
