# 명조 · 공명전선

명조 캐릭터 25명으로 조합을 실험하는 비공식 로컬 팬 프로토타입. 혼자 9구역 원정 또는 같은 와이파이에서 2~8인 대전. 기존 애니메이션 크로스오버 게임과 별도 폴더로 유지합니다.

## 실행

이 폴더에서 `npm start`, 브라우저에서 http://localhost:4190/ 를 엽니다. Node.js 필요. `npm test`로 전투·경제·저장 검사를 실행합니다.

## 플레이

1. 8가지 시작 팀 중 하나를 고릅니다(젠니 광휘·카르티시아 침식 포함).
2. 상점에서 같은 캐릭터 3명을 모으면 자동 승급하고, 사본을 모을 때마다 공명 체인이 열립니다. 캐릭터 선택 후 빈 전장·대기석 칸을 누르면 이동합니다.
3. 캐릭터를 선택하고 에코 가방의 장비를 눌러 장착합니다.
4. 전투는 자동 진행됩니다. 협주 100일 때 총공격 버튼을 직접 누릅니다.
5. 전투 후 에코와 다음 경로를 선택합니다. 3·6구역에서 공명 변주를 선택하고 9구역까지 도전합니다.

준비 단계가 브라우저에 자동 저장됩니다. 전투 중 새로고침은 전투 직전 준비 단계로 돌아갑니다. 보상 선택 중 저장은 지원하지 않습니다. 새 원정은 확인 후 저장을 초기화합니다.

### 함께 대전 실행
1. 방장 컴퓨터에서 `npm start` (또는 `플레이.command`). 터미널에 `같은 와이파이 친구 접속 → http://192.168.x.x:4190/` 주소가 표시됩니다. macOS 방화벽 허용 창이 뜨면 허용하세요.
2. 방장: **함께 대전 → 방 만들기**. 4자리 방 코드가 나옵니다.
3. 친구: 같은 와이파이에서 위 주소 접속 → **함께 대전** → 코드 입력 → 참가. 인원이 부족하면 방장이 **봇 추가**(최대 8명).

### 공명 체인 (중복 강화)
TFT식 3장 합성(★★ 3장, ★★★ 9장)은 그대로 두고, 명조의 공명 체인처럼 **사본 1장마다** 효과가 하나씩 열립니다. 2장째부터 바로 강해지므로 중복 영입이 매번 의미 있습니다. 사본은 ★에 따라 1·3·9장으로 계산하고, 팔면 다시 닫힙니다.

| 체인 | 필요 사본 | 효과 |
|---|---|---|
| 1 공명의 각성 | 2 | 공격력·최대 체력 +8% |
| 2 가속하는 주파수 | 3 (★★) | 해방 필요 공격 횟수 −1 |
| 3 변주 연계 | 4 | 해방 직후 다음 아군이 **변주 입장** 공격(공격력 80%) |
| 4 공명 증폭 | 5 | 해방 피해 +25% |
| 5 잔향 수호 | 7 | 시작 보호막 120 · 해방마다 협주 +8 |
| 6 잔향의 메아리 | 9 (★★★) | 해방이 60% 위력으로 한 번 더 발동 |

상점 카드의 `체인 n → n+1`, 전장 타일의 `Cn`, 캐릭터 정보의 6칸 목록에서 확인합니다. 멀티 대전과 봇에도 같은 규칙이 적용됩니다.

### 도트 전투 연출
전투가 시작되면 모든 유닛이 18×24 도트 캐릭터로 바뀌어 전열로 걸어 나간 뒤, 근접형(검·창·주먹)은 대상에게 돌진해 베고 원거리형(총·지팡이·오브)은 탄을 쏩니다. 피격 시 번쩍임과 넉백이 나오고, 해방 때는 점프와 파동, 쓰러지면 쓰러지는 모션이 나옵니다. 머리 위 체력 바와 피해 숫자가 따라다닙니다. 도트는 이미지 파일 없이 `sprites.js`의 픽셀 격자로 그립니다. `연출 OFF`면 이동 없이 번쩍임만 표시합니다.

자동 검사 32개 통과. 혼자 원정 1~3구역을 PC 1440×900과 모바일 375×812 브라우저에서 확인했습니다. 함께 대전(봇 1명)에서도 상대 덱이 도트로 재생되는 것을 확인했습니다. 실제 기기 2대 이상의 동시 접속은 아직 확인하지 않았습니다.

- **유대 패널 정리**: 발동한 유대만 설명과 함께 크게, 1/2 단계는 한 줄, 미발동 유대는 작은 칩으로 접음. 선택한 공명자 정보(공명 체인 6칸 포함)가 스크롤 없이 보이고, 선택 시 자동으로 해당 위치로 이동.
- **가독성**: 7~9px이던 글자 82곳을 PC 기준 10~13px 이상으로 키움.
- **기타**: 코인이 부족한 카드는 흑백 + "코인 부족" 표시, 협주 버튼은 캡슐형 게이지, 전투가 시작되면 중앙 안내 문구가 전투 안내로 바뀜, 모바일 헤더 줄바꿈 수정.

## 2026-10-13 · 캐릭터별 도트 디자인
공용 틀에 색만 바꾸던 18×24 도트를 **24×32 캐릭터별 도트**로 다시 그렸습니다. 각 공명자는 체형(드레스·짧은 치마·코트·정장) + 머리 모양(앞머리 6종, 뒷머리 9종: 긴 머리·웨이브·단발·트윈테일·드릴·포니테일·묶은 머리·땋은 머리) + 고유 소품 + 무기를 픽셀 격자로 조합합니다.

예: 젠니(흰 장발·검은 뿔·빨간 넥타이·건틀릿), 페비(챙 넓은 흰 모자·십자 지팡이), 카르티시아(가시 왕관·엘프 귀), 아우구스타(금빛 왕관·창), 능양(흰 갈기·사자 귀), 칸타렐라(머리 장식·해파리), 앙코(트윈테일·양 인형), 카를로타(드릴 머리·리본·총), 모르테피(안경·쌍권총), 유노(월계관·초승달), 샤콘(땋은 머리·뿔·리라).

전체 모습 확인: `node tools/sprite-sheet.mjs docs/sprites.png` → [docs/sprites.png](docs/sprites.png)

### 포트레이트 기준 보정
각 공명자의 일러스트(`assets/heroes`, 기존 초상화 시트)를 보고 도트의 머리·눈·의상 색과 특징을 맞췄습니다. 상의/하의 색을 분리하고 파츠를 추가했습니다: 파수인 흰 베일, 카를로타 붉은 리본, 플로로 금빛 후광, 절지 안경·올림머리, 앙코 분홍 리본·흑백 의상, 모르테피 붉은 머리·흰 코트, 상리요 은발·흰 코트·기계 건틀릿, 산화 은발 장발·검은 의상·이마 표식, 페비 파란 X 핀, 능양 검은 사자 귀·머리띠, 루파 금띠 뿔, 샤콘 엘프 귀, 젠니 검은 장갑.

## 2026-10-13 · 휴대폰 가로 전용
- 휴대폰은 **가로 화면 전용**입니다. 세로로 들면 "휴대폰을 가로로 돌려 주세요" 안내만 표시됩니다.
- 가로(높이 540px 이하)에서는 왼쪽 유대 · 가운데 전장/대기석 · 오른쪽 세로 상점 열로 배치해 스크롤 없이 한 화면에 들어갑니다(667×375 ~ 932×430 확인).

- 홈 화면에 추가하면 `manifest.webmanifest` 설정에 따라 전체 화면 · 가로로 열립니다.
